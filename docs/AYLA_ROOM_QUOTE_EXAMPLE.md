# Ayla room-based quote example

For a bathroom-only domestic quote, Ayla should create one client cost centre:

## Bathroom

Client Information / Description:

- Remove existing bath and associated waste
- Supply and install 1200mm shower tray and waste
- Alter hot, cold and waste pipework to suit the new layout
- Replace WC and wash-hand basin
- Retain existing towel radiator
- Test and commission plumbing on completion

Internal Blake build-up remains under the same Bathroom cost centre and is not shown on the client quote by default:

- material quantities and cost prices
- material markup / sell prices
- plumber labour hours, cost rate and sell rate
- rolled-up Bathroom sell total and margin

If kitchen work is added, create a separate `Kitchen` cost centre. Do not create client cost centres named First Fix, Second Fix, Testing or Commissioning unless the user explicitly requests that presentation.
